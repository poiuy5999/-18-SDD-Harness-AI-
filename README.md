# SDD 规范驱动 + Harness 驾驭工程 AI 全栈开发

随着 Vibe Coding 这类仓库级 AI 编码智能体在开发领域快速普及，很多开发者都体验到 AI 快速生成代码的强大能力，但在落地工程项目时普遍遭遇相同困境：AI 生成代码速度快，却常常擅自修改核心模块、随意重构架构，产出大量隐藏 bug，项目大多只能停留在 Demo 原型阶段，难以交付可维护、可上线的企业级工程。**SDD 规范驱动 + Harness 驾驭工程 AI 全栈开发**课程，核心目标就是传授一套工程化管控方法论，不再单纯依赖 AI 自由发挥写代码，而是通过预先定义的设计契约 + 自动化质检流水线，约束、校验、修正 AI 的编码产出，真正驾驭 AI 编码智能体完成稳定、可落地的全栈项目开发。

课程开篇会直面 AI 编码的核心痛点，剖析大模型代码幻觉、架构漂移、模块边界混乱的底层成因。很多开发者使用 AI 编码的误区，就是直接丢需求给 AI，没有任何前置约束，任由 AI 自由修改仓库里任意文件。课程首先建立核心理念：**SDD 是给 AI 阅读的软件设计契约，是整个 AI 开发流程的源头约束**。课程详细讲解 SDD（Software Design Document，面向 AI 智能体的软件设计文档）的编写规范、粒度控制与模板使用。在启动项目编码之前，就预先定义整套系统分层架构、模块划分、数据库表结构、实体模型、接口入参出参、第三方依赖版本、编码规范，并且明确划定代码保护区域，标注哪些核心文件、核心逻辑禁止修改，哪些模块仅允许追加新功能，禁止改动原有业务逻辑。

课程会区分不同规模项目的 SDD 编写策略：小型工具项目 SDD 可以精简，重点锁定数据模型与核心接口；SaaS 级多模块项目，则需要细化模块依赖、权限逻辑、存储设计。课程提供可直接复用的 SDD 模板，手把手演示如何将模糊的产品需求，转化为 AI 编码 Agent 能够读懂、遵守的标准化契约。SDD 的价值，就是从源头降低大模型幻觉带来的架构破坏，让 AI 所有编码行为都必须遵循预先约定的设计方案，避免 AI 为了实现功能随意推翻原有架构。

Harness 自动化质检流水线，是这套体系的质量守门人，也是 SDD 规范的自动化执行抓手。课程系统讲解 Harness 流水线完整搭建思路，串联静态代码扫描、类型校验、单元测试、架构规则校验、安全漏洞扫描四大能力。当 Vibe Coding 编码 Agent 完成代码编写并提交变更，Harness 会自动执行全量校验，检查代码是否符合 SDD 契约约定，一旦检测出语法错误、逻辑缺陷、架构违规、安全漏洞，会整理结构化、可读性强的错误信息，回传给编码 Agent，驱动 AI 自主迭代修复代码。针对数据库表结构修改、权限逻辑变更等高风险改动，流水线会直接触发**人在回路**审批机制，暂停自动迭代流程，等待人工审核确认之后，才能继续执行，规避 AI 擅自修改核心业务带来的线上风险。由此形成闭环开发流程：SDD 预先定义规范 → AI 编码实现功能 → Harness 自动化校验 → 反馈缺陷自动修复，循环迭代，持续保障代码质量。

课程依托前沿技术栈开展完整全栈项目实战，采用 React19+Elysia+Bun，从零开发一套 AI 原生 Web 应用。前端使用 React19，基于 Server Components、流式渲染，搭建任务看板、智能体对话面板、人工审批后台、权限管理页面。后端基于 Bun 运行时的 Elysia 高性能框架，完成数据模型设计、数据库交互、类型安全 API、身份鉴权等业务逻辑。整个项目开发全程贯彻 SDD+Harness 这套管控体系：先撰写 SDD 文档锁定架构与接口规范，再指挥 AI 编码 Agent 开发前后端代码，每一轮代码提交都会触发 Harness 流水线自动校验，不合格代码自动回传给 AI 修复。学员完整体验从需求到代码、从开发到校验的全流程，学会在实战中调整 SDD 粒度，优化 Harness 校验规则，处理 AI 编码过程中各类架构违规、代码缺陷问题。

项目开发完成之后，进入 DevOps 工程交付环节。学习 Docker 容器多阶段构建、镜像瘦身、CI/CD 流水线配置，实现代码提交后自动拉取代码、自动执行 Harness 全套测试、自动构建镜像、自动部署。搭建日志采集、链路追踪、指标告警的全链路可观测体系，掌握灰度发布、熔断限流、大模型调用成本统计，保障经过 SDD 约束、Harness 校验后的 AI 生成代码安全发布到生产环境，处理线上并发异常、接口报错等运维问题。

课程进阶模块讲解多智能体协同场景下的 SDD 与 Harness 应用。学员学习将 Harness 质检能力封装成标准化 Skill，接入 DeepAgents+MCP+A2A+Skills 超级多智能体集群。DeepAgents 接收顶层业务需求，完成任务拆解，通过 A2A 协议在不同角色智能体之间传递任务与上下文。编码 Skill 负责开发代码，Harness 质检 Skill 自动校验产出是否符合 SDD 规范，还可以联动图像生成 Skill、AIOps 运维 Skill，实现需求下发、开发、质检、部署一体化自动化研发流水线。课程讲解集群场景下的权限管控、调用审计、任务重试策略，同时讲解架构选型边界，避免简单项目过度引入多智能体，增加不必要的维护成本。

课程配套全套学习资源，包含 SDD 文档模板、Harness 流水线配置脚本、项目源码、测试用例库、踩坑案例集。讲师结合大量工程落地真实案例，讲解架构漂移、上下文污染、测试用例失效、AI 擅自修改核心表结构等高频问题的排查方案。课程适合全栈开发者、技术负责人、架构师、独立开发者，以及想要在团队内部落地 Vibe Coding 开发模式的技术人员。

完成课程学习之后，学员不再只是简单使用 AI 生成代码片段，而是掌握一套完整的工程化 AI 编码管控体系。学会通过 SDD 提前锁定项目设计，依靠 Harness 自动化流水线持续校验代码质量，驾驭 AI 编码 Agent 完成可控、可维护的全栈项目开发。同时理解多智能体集群协同架构，能够搭建安全可靠的自动化研发流水线，把 AI 编码能力真正落地到企业生产环境，在 AI 重塑软件研发的浪潮中，提升个人与团队的研发交付效率。
